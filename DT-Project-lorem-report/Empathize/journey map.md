# First (ก่อนเกิดเหตุการณ์ / ก่อนโดนตักเตือน):
ความรู้สึก: มั่นใจในตัวเองที่ได้แต่งตัว แต่งหน้า หรือทำทรงผมตามสไตล์ที่ชอบ บางคนรู้สึกเร่งรีบเนื่องจากกังวลว่าจะเข้าเรียนไม่ทันเวลา หรือรู้สึกโกรธและอึดอัดขัดใจเมื่อถูกเพื่อนเอาเปรียบเรื่องทรัพย์สิน รวมถึงมีความกังวลและกดดันจากสภาพแวดล้อมรอบข้างเกี่ยวกับสิ่งเสพติด
การกระทำ: แต่งกาย ย้อมสีผม ซอยสไลด์ผม หรือแต่งหน้าจัดมาโรงเรียนเพื่อเพิ่มความมั่นใจ วิ่งเร่งรีบขึ้นห้องเรียนหลังสัญญาณออดดัง ทวงถามทรัพย์สินคืนจากเพื่อน และสังเกตการณ์พฤติกรรมของเพื่อนในกลุ่มพร้อมพยายามหลีกเลี่ยงการกระทำผิดวินัย

# Next (ระหว่างเกิดเหตุการณ์และถูกตักเตือน - จุดพีคและจุดดรอป):
จุดพีค: รู้สึกโล่งใจเมื่อสามารถแก้ไขสถานการณ์เฉพาะหน้าได้ทันที เช่น การรีบเอาเสื้อใส่ในกางเกงแล้วครูอนุโลม หรือการได้เงินคืนและปรับความเข้าใจกันได้ รวมทั้งรู้สึกดีที่เห็นครูเตือนเพื่อนด้วยน้ำเสียงรับฟังและใช้วิธีการตักเตือนเชิงแนะนำ
จุดดรอป: พบอุปสรรคและประสบการณ์ลบ เช่น การถูกครูดุสาดหรือถูกตักเตือนต่อหน้าผู้อื่นจนเสียความมั่นใจ การถูกสั่งให้ถักเปียใหม่ทันที ลบหน้าสด หรือย้อมผมกลับ การขาดสติจนเกิดพฤติกรรมความรุนแรงชกต่อยกัน ทัศนคติของครูที่ตัดสินว่าการแต่งหน้าหรือทรงผมทำให้การเรียนแย่ลง ความรู้สึกผิดที่ตนเองรอดการลงโทษคนเดียวในขณะที่เพื่อนโดนลงโทษอย่างหนัก และความกังวลว่าบทลงโทษที่รุนแรงเกินไป (เช่น การไล่ออก) จะเป็นการตัดอนาคตทางการศึกษา

# Then (หลังเกิดเหตุการณ์และผลกระทบ):
ความรู้สึก: รู้สึกยอมรับและเข้าใจในกฎระเบียบบางข้อที่เป็นเรื่องความเรียบร้อยพื้นฐาน แต่ลึกๆ ยังคงอึดอัด ตั้งข้อสงสัย และอยากให้โรงเรียนเปิดกว้างมอบเสรีภาพในการแสดงออก รู้สึกเสียใจภายหลังหากต้องใช้ความรุนแรงแก้ไขปัญหา และอยากเห็นระบบการลงโทษที่เปลี่ยนจากการตัดโอกาสเป็นการบำบัด ปรับพฤติกรรม และช่วยเหลือนักเรียนอย่างจริงจัง
