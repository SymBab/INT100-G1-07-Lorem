# Persona 1: โลตัส (ม.1 โรงเรียนนาหลวง)-ประเด็น: เครื่องแต่งกาย
# First (จุดเริ่มต้น)
*ความรู้สึก :* เร่งรีบและไม่อยากเอาเสื้อเข้าในกางเกง 
การกระทำ: พอออดดังจึงรีบวิ่งขึ้นห้องเรียนเพื่อเข้าเรียนวิชาถัดเลยเอาเสื้อออกนอกกางเกง

# Next (ระหว่างเกิดเหตุ - จุดพีคและจุดดรอป)
*จุดพีค :* รู้สึกสบายใจและยอมแก้ไขทันทีเมื่อครูเตือน
จุดดรอป: เสื้อหลุดลุ่ยออกนอกกางเกงเนื่องจากความเร่งรีบ และถูกครูทักท้วงต่อหน้าผู้อื่นเรื่องความไม่เรียบร้อยฃ

# Then (หลังเกิดเหตุเสร็จสิ้น)
*ความรู้สึก :* รู้สึกยอมรับแล้วก็ยินดีทำตามครู และมองว่ากฎระเบียบเรื่องการใส่เสื้อในกางเกงมีความยุติธรรม ช่วยให้ดูเป็นระเบียบเรียบร้อย

<br>

# Persona 2: เมย่า (ม.1 โรงเรียนนาหลวง)-ประเด็น: ทรงผมและสีผม
# First (จุดเริ่มต้น)
*ความรู้สึก :* มั่นใจในตัวเองและรู้สึกมีอิสระในการแสดงออก
การกระทำ: ทำผมทรงซอยสไลด์และย้อมผมสีน้ำตาลมาโรงเรียน


# Next (ระหว่างเกิดเหตุ - จุดพีคและจุดดรอป)
*จุดพีค :* รู้สึกโล่งใจที่ครูยอมอนุโลมให้ในกรณีที่เป็นสีผมธรรมชาติ
จุดดรอป: โดนครูตักเตือนเรื่องทรงผมผิดระเบียบ และรู้สึกอึดอัดกับความคิดของครูที่ตัดสินว่าทรงผมส่งผลต่อการเรียน

# Then (หลังเกิดเหตุเสร็จสิ้น)
*ความรู้สึก :* รู้สึกต้องทำตามที่ครูสั่งเลยต้องรีบเข้าห้องน้ำไปถักเปียใหม่ แต่ลึกๆยังอยากให้โรงเรียนให้เสรีภาพเรื่องทรงผมเพราะมองว่าไม่เกี่ยวกับการเรียน

<br>

# Persona 3: เปตอง (ม.2 โรงเรียนวัดพุทธบูชา)-ประเด็น: ข้อขัดแย้งและการใช้ความรุนแรง
# First (จุดเริ่มต้น)
*ความรู้สึก :* โกรธและรู้สึกไม่ได้รับความยุติธรรม
การกระทำ: พยายามทวงเงิน10บาทคืนจากเพื่อนในห้องเรียนแต่เพื่อนไม่ยอมคืน

# Next (ระหว่างเกิดเหตุ - จุดพีคและจุดดรอป)
*จุดพีค :* ได้เงิน 10 บาทคืนเรียบร้อยและแยกย้ายกันด้วยดี
จุดดรอป: ขาดสติและใช้อารมณ์นำจนเกิดการชกต่อยกับเพื่อนในห้องเรียนจนเพื่อนฟันหลุด

# Then (หลังเกิดเหตุเสร็จสิ้น)
*ความรู้สึก :* รู้สึกโล่งใจที่ครูจับไม่ได้ แต่เมื่อนึกย้อนกลับไปก็รู้สึกเสียใจและมองว่าถ้าย้อนเวลาได้อยากได้เงินคืนตั้งแต่แรกโดยไม่ต้องต่อยกัน

<br>

# Persona 4: พิทยา (ม.4 โรงเรียนนาหลวง) — ประเด็น: บุหรี่
# First (จุดเริ่มต้น)
*ความรู้สึก :* กดดันจากสภาพแวดล้อมรอบข้าง และต้องระมัดระวังตัวในการวางตัวกับกลุ่มเพื่อน
การกระทำ: ฟังเพื่อนเล่าประสบการณ์เกี่ยวกับบุหรี่ แต่พยายามหลีกเลี่ยงไม่สูบด้วยตัวเอง

# Next (ระหว่างเกิดเหตุ - จุดพีคและจุดดรอป)
*จุดพีค :* ดีใจที่ตนเองวางตัวดีและรอดพ้นจากการกระทำผิดกฎ
จุดดรอป: เห็นเพื่อนในกลุ่มโดนอาจารย์ตักเตือนเรื่องสูบบุหรี่ และรู้สึกผิดในใจที่ตนเองรอดอยู่คนเดียวในขณะที่เพื่อนถูกลงโทษ

# Then (หลังเกิดเหตุเสร็จสิ้น)
*ความรู้สึก :* เห็นด้วยว่าการเตือนเป็นสิ่งยุติธรรมเพราะบุหรี่ไม่ดี แต่ยังคงคบกับเพื่อนตามปกติ และอยากให้ลดความรุนแรงของบทลงโทษลงไม่ถึงขั้นไล่ออก

<br>

# Persona 5: ของขวัญ (ม.1 โรงเรียนนาหลวง)-ประเด็น: การแต่งหน้า
# First (จุดเริ่มต้น)
*ความรู้สึก :* อยากสร้างความมั่นใจให้ตนเอง และเข้าใจความต้องการของเพื่อน
การกระทำ: สังเกตเห็นเพื่อนแต่งหน้าจัดมาโรงเรียนทุกวัน และตนเองก็อยากแต่งหน้าบางๆ อ่อนๆ มาเรียนบ้าง

# Next (ระหว่างเกิดเหตุ - จุดพีคและจุดดรอป)
*จุดพีค :* รู้สึกดีหากได้รับการยอมรับให้แต่งหน้าบางๆ เพราะช่วยเพิ่มความมั่นใจ
จุดดรอป: เห็นเพื่อนโดนครูตักเตือนเรื่องแต่งหน้าและบังคับให้หน้าสด เลยรู้สึกอึดอัดกับคำตัดสินที่ว่าการแต่งหน้าส่งผลเสียต่อการเรียน

# Then (หลังเกิดเหตุเสร็จสิ้น)
*ความรู้สึก :* มองว่าการแต่งหน้าไม่เกี่ยวกับการเรียน และอยากให้ปรับกฎระเบียบให้มีความเสรีมากขึ้น
