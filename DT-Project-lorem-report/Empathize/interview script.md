## Interview Script

**Persona 1: โลตัส (Lotus) — ม.1 โรงเรียนนาหลวง**

- **Q: ช่วยเล่าเหตุการณ์ที่เคยโดนอาจารย์ตักเตือนเกี่ยวกับกฎระเบียบในโรงเรียนให้ฟังหน่อย**
    - **A:** โดนตักเตือนเรื่อง**เอาเสื้อออกนอกกางเกง**ครับ ตอนนั้นเป็นชั่วโมงวิชาพละ พอสัญญาณออดดังก็รีบวิ่งขึ้นห้องเรียนจนเสื้อหลุดออกนอกกางเกง ครูเลยทักว่าทำไมไม่เรียบร้อยและบอกให้เอาเสื้อใส่ในกางเกงด้วย
- **Q: ตอนที่โดนตักเตือน รู้สึกอย่างไรบ้าง**
    - **A:** รู้สึกว่า**เราทำผิดจริง ๆ** และควรจะเอาเสื้อใส่กางเกงให้เรียบร้อยตั้งแต่แรกอยู่แล้วครับ
- **Q: คิดว่ากฎข้อนี้ยุติธรรมไหม เพราะอะไร**
    - **A:** **ยุติธรรมครับ** เพราะมันเป็นกฎระเบียบของโรงเรียนอยู่แล้ว และช่วยทำให้ร่างกายของเราดูเป็นระเบียบเรียบร้อยด้วย
- **Q: หลังจากโดนตักเตือนแล้วทำอย่างไรต่อ**
    - **A:** ก็**เอาเสื้อใส่ในกางเกงทันที**ครับ

---

**Persona 2: เมย่า (Maya) — ม.1 โรงเรียนนาหลวง**

- **Q: ช่วยเล่าเรื่องที่โดนตักเตือนเกี่ยวกับกฎระเบียบของโรงเรียนให้ฟังหน่อย**
    - **A:** โดนตักเตือนเรื่อง**ทรงผมกับสีผม**ค่ะ เรื่องผมโดนเพราะซอยสไลด์ (สไลด์เลเยอร์) เยอะเกินไป และทำผมสีน้ำตาล ซึ่งกฎจริง ๆ ของโรงเรียนคือต้องถักเปีย ห้ามมีหน้าม้า และต้องเก็บปอยผมให้เรียบร้อย
- **Q: ตอนที่โดนทักเรื่องทรงผมผิดระเบียบ จัดการอย่างไรบ้าง**
    - **A:** ตอนนั้นก็รีบ**เข้าห้องน้ำไปถักเปียใหม่ทันที**ค่ะ
- **Q: คิดอย่างไรกับกฎระเบียบเรื่องทรงผม**
    - **A:** ถ้าทำตามมันก็ดูเป็นระเบียบเรียบร้อยดีทุกคนค่ะ แต่ลึก ๆ ก็**อยากให้มีเสรีภาพเรื่องทรงผม** เพราะอาจารย์หลายท่านชอบบอกว่าทรงผมจะทำให้การเรียนแย่ลง แต่ส่วนตัวรู้สึกว่า**มันไม่เกี่ยวกันเลยค่ะ**
- **Q: แล้วถ้ามีคนที่ผมเป็นสีน้ำตาลธรรมชาติอยู่แล้ว อาจารย์จะทำอย่างไร**
    - **A:** อาจารย์ยอมให้ค่ะ แต่ว่าเขาจะเช็คก่อนว่าเป็นลูกครึ่งจริงหรือเปล่า ส่วนเพื่อนคนอื่นที่โดนให้ไปย้อมดำใหม่ มักจะเป็นกรณีที่ย้อมสีผมมาก่อนแล้วย้อมกลับไม่หมดค่ะ    


---

**Persona 3: เปตอง (Petong) — ม.2 โรงเรียนวัดพุทธบูชา**

- **Q: ช่วยเล่าเหตุการณ์ในโรงเรียนที่เคยโดนตักเตือนเรื่องกฎระเบียบ (ย้อนไปช่วงประถมก็ได้)**
    - **A:** ตอน ป.4 เคยมีเรื่อง**ชกต่อยกับเพื่อนในห้องเรียน**ครับ ทะเลาะกันเพราะ**เพื่อนไม่ยอมคืนเงิน 10 บาท** โมโหมากก็เลยต่อยกัน
- **Q: ตอนต่อยไปแล้ว รู้สึกอย่างไรบ้าง**
    - **A:** รู้สึก **"มัน"** ครับ
- **Q: แล้วโดนอาจารย์จับได้หรือโดนทำโทษไหม**
    - **A:** **ไม่โดนครับ** เรื่องเงียบไปเลย แต่เพื่อนฟันหลุดครับ
- **Q: แล้วตอนนั้นน้องคิดอย่างไรถึงทำให้ต่อยเพื่อน**
    - **A:** อารมณ์มันพาไปครับ
- **Q: ตอนนี้ได้เงินคืนหรือยัง**
    - **A:** **ได้คืนเรียบร้อยแล้ว**และแยกย้ายกันดีครับ
- **Q: ถ้าย้อนเวลากลับไปได้และเลือกตัวช่วยได้ อยากได้อะไร**
    - **A:** อยากได้**เงิน 10 บาทคืนตั้งแต่แรกครับ** (จะได้ไม่ต้องต่อยกัน)

---

**Persona 4: พิทยา (Phittaya) — ม.4 โรงเรียนนาหลวง**

- **Q: เหตุการณ์ล่าสุดที่โดนตักเตือนเรื่องทำผิดกฎระเบียบในโรงเรียนคืออะไร**
    - **A:** ตั้งแต่ย้ายมาโรงเรียนใหม่**ยังไม่เคยโดนตักเตือนเลยครับ** แต่เคยเห็นเพื่อนโดนตักเตือนเรื่อง**สูบบุหรี่**
- **Q: คิดอย่างไรเกี่ยวกับบุหรี่ และคิดอย่างไรกับเพื่อนที่สูบ**
    - **A:** คิดว่าบุหรี่มันไม่ดีครับ แต่กับเพื่อนที่โดนตักเตือนก็ไม่ได้ซีเรียสอะไร ยังเล่นด้วยกันได้ตามปกติครับ
- **Q: น้องเคยคุยกับเพื่อนเกี่ยวกับบุหรี่ไหม ถ้าเคยคุยเรื่องอะไรบ้าง**
		    - **A:** เพื่อนเคยเล่าให้ฟัง ว่ากลิ่น เป็นยังไง ความรู้สึกตอนดูดเป็นยังไง
- **Q: คิดว่ายุติธรรมไหมที่เพื่อนโดนอาจารย์เตือน หรือโรงเรียนควรปล่อยเสรีเรื่องสูบบุหรี่**
    - **A:** **ยุติธรรมครับ** เพราะถ้าเริ่มสูบตั้งแต่เด็กจะติดไปจนโต ซึ่งมองว่าเป็นสิ่งไม่ดี
- **Q: รู้สึกกดดันไหมถ้าคนรอบข้างหรือเพื่อนรอบตัวสูบบุหรี่กันเยอะ**
    - **A:** **กดดันอยู่บ้างครับ** รู้สึกว่าตัวเองต้องพยายามหลีกเลี่ยง
- **Q: ถ้าเลือกเปลี่ยนแปลงกฎเรื่องนี้ได้ อยากปรับปรุงตรงไหน**
    - **A:** เรื่องของบุหรี่**อยากให้ลดความรุนแรงของบทลงโทษลงหน่อย** ไม่ถึงขั้นไล่ออกหรือพักการเรียน แต่ยังคงมีการทำโทษอยู่เหมือนเดิมครับ
- **Q: ถ้ามีเหตุการณ์ที่ตัวเองรอดคนเดียวแต่เพื่อนโดนลงโทษ จะรู้สึกอย่างไร**
    - **A:** รู้สึก**ผิดในตัวเอง**ครับว่าทำไมเราถึงรอดอยู่คนเดียวในขณะที่เพื่อนโดนทำโทษ

---

**Persona 5: ของขวัญ (Khongkwan) — ม.1 โรงเรียนนาหลวง**

- **Q: เล่าเรื่องล่าสุดที่โดนตักเตือนเกี่ยวกับกฎระเบียบ (หรือเรื่องที่เพื่อนโดนตักเตือนก็ได้)**
    - **A:** เล่าเรื่อง**เพื่อนแต่งหน้าจัดเกินไป**ค่ะ แต่งหน้ามาโรงเรียนทุกวัน ครูเตือนว่าห้ามแต่งแต่เพื่อนก็ยังแต่งมาทุกวัน คือต้องหน้าสดมาโรงเรียน
- **Q: คิดอย่างไรกับกฎระเบียบห้ามแต่งหน้ามาโรงเรียน**
    - **A:** คิดว่า**น่าจะถูกต้องแล้วค่ะ** เพราะมันเป็นกฎระเบียบที่ยังไงเราก็ต้องทำตามในฐานะที่เป็นนักเรียน
- **Q: เพื่อน ๆ ส่วนใหญ่ที่คุยกันคิดอย่างไรกับกฎข้อนี้**
    - **A:** เพื่อน ๆ **ไม่ค่อยเห็นด้วยเท่าไหร่ค่ะ**
- **Q: ถ้าปรับเปลี่ยนกฎข้อนี้ได้ อยากให้เป็นแบบไหน**
    - **A:** อยากให้**แต่งหน้าบาง ๆ อ่อน ๆ ได้บ้างค่ะ** เพราะเวลาแต่งหน้าแล้วจะรู้สึก**มั่นใจขึ้นนิดหน่อย** (ถ้าอากาศไม่ร้อน)
- **Q: คิดเห็นอย่างไรกับประเด็นที่ว่า "การแต่งหน้าส่งผลเสียต่อการเรียน"**
    - **A:** **ไม่เกี่ยวกันเลยค่ะ**
- **Q: ระหว่างปล่อยให้แต่งหน้าแต่งตัวเสรี กับโดนจำกัดแบบนี้ คิดว่าแบบไหนช่วยให้การเรียนดีขึ้น**
    - **A:** **แบบเสรีค่ะ** เพราะมันไม่เกี่ยวกับการเรียน การเรียนก็คือเรื่องเรียน และกฎที่เสรีจะทำให้นักเรียนรู้สึกเหมือนได้ปลดปล่อยด้วยค่ะ
