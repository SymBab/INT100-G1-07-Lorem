# Test Result

### โลตัส (ม.1, ชาย, โรงเรียนนาหลวง)

**เป้าหมาย:** ปฏิบัติตามกฎระเบียบของโรงเรียนให้เรียบร้อย
**Motivations:** เชื่อว่ากฎมีเหตุผลและช่วยให้ร่างกายดูเป็นระเบียบ
**Frustrations:** การทำผิดกฎโดยไม่ได้ตั้งใจจากความรีบเร่งในการเปลี่ยนวิชาเรียน

1. **การมองหน้าแรก (Dashboard):**
   มองเห็นคะแนนความประพฤติ ระดับ Tier และกิจกรรมล่าสุดได้ง่าย ทำให้รู้สถานะของตัวเองได้ทันที

2. **ความชัดเจนของสีและสัญลักษณ์:**
   สีและ Badge ช่วยให้เข้าใจสถานะคะแนนและสถานะการอุทธรณ์ได้ง่าย แต่ควรใช้สีที่แตกต่างกันอย่างชัดเจน

3. **หน้าชี้แจง / ยื่นอุทธรณ์:**
   ขั้นตอนค่อนข้างเข้าใจง่าย โดยเฉพาะการอธิบายเหตุผลและแนบหลักฐาน เพราะสามารถใช้ชี้แจงกรณีที่ทำผิดโดยไม่ได้ตั้งใจได้

4. **ประวัติและสรุปผล:**
   มีประโยชน์ในการตรวจสอบว่าตนเองเคยถูกหักคะแนนจากเหตุการณ์ใดบ้าง และสามารถติดตามการเปลี่ยนแปลงของคะแนนได้

5. **ความโปร่งใสและความเป็นธรรม:**
   ช่วยให้รู้สาเหตุของการถูกหักคะแนนและมีโอกาสอธิบายเหตุการณ์ที่เกิดขึ้น จึงเหมาะกับกรณีที่เกิดจากเหตุสุดวิสัย

6. **จุดที่อาจใช้งานผิดวัตถุประสงค์:**
   อาจมีการยื่นอุทธรณ์ในกรณีที่ทำผิดจริง ดังนั้นควรมีหลักฐานหรือข้อมูลประกอบการชี้แจง

### เมย่า (ม.1, หญิง, โรงเรียนนาหลวง)

**เป้าหมาย:** มีเสรีภาพในการเลือกทรงผมของตัวเอง
**Motivations:** เชื่อว่าทรงผมไม่มีผลกระทบต่อการเรียน
**Frustrations:** กฎที่ดูไม่มีเหตุผลและการบังคับใช้ที่ไม่ยุติธรรม

1. **การมองหน้าแรก (Dashboard):**
   สามารถตรวจสอบคะแนนและสถานะของตัวเองได้ง่าย ทำให้เห็นผลจากการถูกตัดคะแนนอย่างชัดเจน

2. **ความชัดเจนของสีและสัญลักษณ์:**
   Badge ควรแสดงสถานะให้ชัดเจน เช่น ถูกหักคะแนนหรืออยู่ระหว่างการพิจารณา เพื่อไม่ให้เกิดความเข้าใจผิด

3. **หน้าชี้แจง / ยื่นอุทธรณ์:**
   มีประโยชน์เพราะสามารถอธิบายเหตุผลของตัวเองและแนบหลักฐานได้ โดยเฉพาะกรณีที่คิดว่าการบังคับใช้กฎไม่เป็นธรรม

4. **ประวัติและสรุปผล:**
   ช่วยให้ตรวจสอบได้ว่าตนเองถูกตัดคะแนนจากเรื่องใดและสามารถดูประวัติย้อนหลังได้

5. **ความโปร่งใสและความเป็นธรรม:**
   ระบบช่วยเพิ่มช่องทางให้นักเรียนแสดงความคิดเห็นและชี้แจงก่อนที่จะถูกตัดสิน ทำให้กระบวนการมีความชัดเจนขึ้น

6. **จุดที่อาจใช้งานผิดวัตถุประสงค์:**
   อาจใช้การอุทธรณ์เพื่อโต้แย้งกฎทุกกรณี จึงควรกำหนดขอบเขตและเงื่อนไขการยื่นคำชี้แจงให้ชัดเจน

### เปตอง (ม.2, ชาย, โรงเรียนวัดพุทธบูชา)

**เป้าหมาย:** ทวงคืนความยุติธรรมและสิ่งที่ควรเป็นของตนเอง
**Motivations:** อารมณ์ชั่ววูบและความโกรธ
**Frustrations:** การถูกเอาเปรียบและการไม่มีทางออกในการแก้ปัญหา

1. **การมองหน้าแรก (Dashboard):**
   การแสดงคะแนนและกิจกรรมล่าสุดช่วยให้ตรวจสอบได้ว่ามีเหตุการณ์อะไรเกิดขึ้นกับตนเอง

2. **ความชัดเจนของสีและสัญลักษณ์:**
   ควรแสดงสถานะของแต่ละเหตุการณ์ให้ชัดเจน โดยเฉพาะสถานะที่กำลังตรวจสอบหรืออุทธรณ์

3. **หน้าชี้แจง / ยื่นอุทธรณ์:**
   ช่วยให้ผู้ใช้มีช่องทางในการอธิบายปัญหาแทนการโต้แย้งด้วยอารมณ์ และสามารถแนบหลักฐานประกอบได้

4. **ประวัติและสรุปผล:**
   การมีประวัติย้อนหลังช่วยให้ตรวจสอบเหตุการณ์ได้เป็นลำดับและลดความเข้าใจผิดเกี่ยวกับคะแนน

5. **ความโปร่งใสและความเป็นธรรม:**
   ระบบเปิดโอกาสให้ผู้ถูกตัดคะแนนชี้แจงเหตุผลและแสดงหลักฐาน ทำให้มีช่องทางแก้ไขปัญหาที่ชัดเจนขึ้น

6. **จุดที่อาจใช้งานผิดวัตถุประสงค์:**
   อาจยื่นอุทธรณ์ด้วยอารมณ์หรือใช้ข้อความที่ไม่เหมาะสม จึงควรมีการกำหนดรูปแบบการชี้แจงให้เหมาะสม

### พิทยา (ม.4, ชาย, โรงเรียนนาหลวง)

**เป้าหมาย:** หลีกเลี่ยงพฤติกรรมที่ไม่ดี แต่ยังรักษาความสัมพันธ์กับเพื่อน
**Motivations:** ต้องการทำสิ่งที่ถูกต้อง แต่ก็กลัวการสูญเสียกลุ่มเพื่อน
**Frustrations:** สภาพแวดล้อมที่กดดัน บทลงโทษที่รุนแรง และความรู้สึกผิดเมื่อเพื่อนถูกลงโทษ

1. **การมองหน้าแรก (Dashboard):**
   การเห็นคะแนนและสถานะปัจจุบันช่วยให้ติดตามพฤติกรรมของตัวเองได้โดยไม่ต้องรอให้เกิดปัญหา

2. **ความชัดเจนของสีและสัญลักษณ์:**
   ควรแยกสถานะต่าง ๆ ให้ชัดเจน เพื่อให้รู้ว่ารายการใดได้รับการยืนยันและรายการใดกำลังพิจารณา

3. **หน้าชี้แจง / ยื่นอุทธรณ์:**
   เป็นช่องทางที่ช่วยให้นักเรียนอธิบายเหตุการณ์หรือบริบทที่เกิดขึ้นได้ โดยไม่จำเป็นต้องเผชิญหน้าหรือโต้แย้งโดยตรง

4. **ประวัติและสรุปผล:**
   มีประโยชน์ในการดูพฤติกรรมย้อนหลังและช่วยให้เห็นแนวโน้มของตนเอง

5. **ความโปร่งใสและความเป็นธรรม:**
   ระบบมีส่วนช่วยให้การตัดสินไม่ได้มีเพียงมุมมองเดียว เพราะนักเรียนสามารถชี้แจงเหตุการณ์และแนบหลักฐานได้

6. **จุดที่อาจใช้งานผิดวัตถุประสงค์:**
   อาจมีการยื่นอุทธรณ์แทนเพื่อนหรือให้ข้อมูลที่ไม่ตรงกับเหตุการณ์จริง จึงควรตรวจสอบหลักฐานก่อนพิจารณา

### ของขวัญ (ม.1, หญิง, โรงเรียนนาหลวง)

**เป้าหมาย:** ต้องการได้รับอนุญาตให้แต่งหน้าอ่อน ๆ ได้
**Motivations:** การแต่งหน้าช่วยเพิ่มความมั่นใจและส่งผลต่อการเรียน
**Frustrations:** กฎที่จำกัดสิทธิเสรีภาพมากเกินไปและส่งผลต่อความมั่นใจ

1. **การมองหน้าแรก (Dashboard):**
   สามารถตรวจสอบคะแนนและสถานะของตัวเองได้ ทำให้รู้ว่าตนเองอยู่ในระดับใด

2. **ความชัดเจนของสีและสัญลักษณ์:**
   ควรทำให้สถานะคะแนนและการอุทธรณ์เห็นได้ชัด เพื่อให้ผู้ใช้เข้าใจผลของการกระทำของตัวเอง

3. **หน้าชี้แจง / ยื่นอุทธรณ์:**
   การมีช่องทางชี้แจงช่วยให้ผู้ใช้สามารถอธิบายเหตุผลของตัวเองและแนบหลักฐานประกอบได้

4. **ประวัติและสรุปผล:**
   ช่วยให้ติดตามคะแนนและดูพฤติกรรมย้อนหลังได้ ทำให้เห็นว่าพฤติกรรมใดส่งผลต่อคะแนน

5. **ความโปร่งใสและความเป็นธรรม:**
   ช่วยเพิ่มความโปร่งใส เพราะนักเรียนสามารถตรวจสอบข้อมูลและมีโอกาสชี้แจงก่อนผลการพิจารณา

6. **จุดที่อาจใช้งานผิดวัตถุประสงค์:**
   อาจใช้ระบบเป็นช่องทางโต้แย้งกฎมากเกินไป จึงควรมีหลักเกณฑ์ในการยื่นอุทธรณ์ที่ชัดเจน
