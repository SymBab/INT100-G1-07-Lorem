# Test Script

### 1. หน้าแรก (Dashboard)
* เมื่อดูหน้าแรกครั้งแรก คุณมองออกทันทีไหมว่าคะแนนความประพฤติคงเหลือ ระดับ Tier และกิจกรรมล่าสุดอยู่ตรงไหน?

* สี สัญลักษณ์ และแถบสถานะ (Badge) ที่ใช้ในแอป ชัดเจนและทำให้เข้าใจสถานะคะแนนและการอุทธรณ์ได้ง่ายหรือไม่? *(มีจุดไหนที่ต้องระวังหรือสับสนไหม?)*

### 2. หน้าชี้แจง / ยื่นอุทธรณ์
* ขั้นตอนการยื่นคำชี้แจงและแนบรูปหลักฐาน ในหน้า "ชี้แจง" ดูแล้วเรียงลำดับสมเหตุสมผล และใช้งานได้ง่ายหรือไม่?

### 3. ประวัติและสรุปผล (History & Summary)
* ส่วนประวัติย้อนหลัง (History) และกราฟสรุปพฤติกรรม (Summary) แสดงข้อมูลเพียงพอและอยู่ในจุดที่นำไปติดตามผลได้จริงหรือไม่?

### 4. ประสิทธิผลและการใช้งานจริง
* เมื่อเทียบกับระบบตัดคะแนนแบบเดิมในโรงเรียน แอปนี้ตอบโจทย์เรื่องความโปร่งใสและให้ความเป็นธรรมกับนักเรียนได้มากน้อยแค่ไหน?

* มีส่วนไหนในแอปนี้ ที่คุณคิดว่าถ้าเอาไปใช้งานจริงแล้ว คนน่าจะหาช่องทางแหกกฎ หรือใช้งานผิดวัตถุประสงค์มากที่สุด?
